# Issue tracker: Linear

Issues and specifications for this repository live in the Linear project “Portfolio” and are managed through an authenticated Linear CLI.

## Conventions

- Create every specification as a Linear issue in the “Portfolio” project.
- Use a concise outcome-oriented issue title.
- Put the complete specification in the issue description.
- Apply triage labels according to `triage-labels.md`.
- Use issue identifiers when referring to work in commits, branches, and follow-up conversations.
- Keep discussion and implementation updates in the Linear issue rather than creating local issue files.

## When a skill says “publish to the issue tracker”

Create an issue in the “Portfolio” project through the Linear CLI, place the complete generated artifact in its description, and apply the requested triage label.

## When a skill says “fetch the relevant ticket”

Read the Linear issue identified by the user. If only a title or topic is provided, search within the “Portfolio” project and confirm the unique match before acting.

## Prerequisite

The Linear CLI must be installed, available on `PATH`, and authenticated for the workspace containing the “Portfolio” project.
