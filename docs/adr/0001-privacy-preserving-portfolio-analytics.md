# Keep portfolio analytics aggregate-only in Redis

Portfolio analytics use Redis as the only datastore and retain aggregate views, HyperLogLog unique estimates, routes, referring domains, and device classes rather than raw events. Unique visitors are deduplicated by the existing anonymous first-party cookie, with a short-lived daily HMAC of the IP only when that cookie is unavailable; raw IPs, full user-agent strings, full referrer URLs, fingerprints, and visitor histories are never stored. Short-lived deduplication keys are independently re-hashed per day, ingestion is allowlisted to known portfolio routes, and the existing `views:global` total remains the canonical all-time count. Collection is limited to `POST /api/analytics/view`, summaries are exposed only through owner-authenticated `/api/admin/analytics`, and `/admin` is restricted to the configured GitHub owner.
