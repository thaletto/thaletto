## Overview

This is a responsive e-commerce platform for pre-owned products, built with Next.js and Tailwind CSS. A decoupled Go microservices architecture supports it, running on AWS Lambda. An event-driven system tracks inventory in real time, managing orders and secure admin controls.

## Approach

The system has three layers, each with a specific responsibility.

**Frontend** uses Next.js with the App Router, mixing Server-Side Rendering with Static Site Generation. It uses Server-Side Rendering for dynamic product pages and Static Site Generation for static content. React Server Components reduce client-side JavaScript, keeping Core Web Vitals fast.

**Backend** contains 7 Go microservices for auth, customers, invoices, notifications, orders, products, and uploads. Each microservice compiles to a single binary, giving fast execution. Lightweight goroutines handle concurrent requests with minimal memory, suiting the high throughput of e-commerce traffic.

**Database** uses Cloudflare D1, a serverless relational database built on SQLite for the edge. Data stays close to the compute layer, removing database connection overhead and complex connection pooling.

## How It Works

- **AWS Lambda:** Go functions compile to single binaries for `GOOS=linux GOARCH=arm64`, using AWS Graviton ARM architecture. This gives up to 34% better price-performance than x86, scaling automatically with traffic and keeping cold starts fast.
- **Event-driven architecture:** Inventory updates, order events, and admin actions flow through an event system, keeping the frontend in sync without polling.
