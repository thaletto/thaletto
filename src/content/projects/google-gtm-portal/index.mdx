## Overview

This is a unified catalog platform for AI offerings from TCS on Google Cloud. Visitors browse and filter the offerings, and request demos for relevant solutions. The team built the platform for Google Cloud Next 2026, optimized for live demonstrations at the event.

## Problem

TCS built many AI solutions on Google Cloud, stored across different team repositories. Each solution worked alone, so visitors could not find them together. A visitor came with a problem but no product name, and could not find a relevant offering.

## Approach

The first challenge was schema. Different teams sent offerings in different formats, with different documentation levels and use-case definitions. The FastAPI backend converts these offerings to one catalog format, keeping the details that describe each offering.

The second challenge was discovery. The platform provides search and filters for use case and industry. Visitors start with a general problem and narrow the list to relevant offerings, matching how visitors search at conferences.

The frontend uses Next.js. It loads quickly and shows clear navigation, helping visitors at a live event.

## How It Works

- **Ingestion:** The FastAPI backend receives offering data in different formats, stored in Google Cloud Storage, and serves one consistent API.
- **Discovery:** Visitors search by use case, industry, and keyword to find relevant AI solutions.
- **Demo requests:** Visitors request a demo for any listed offering, directly from the catalog page.
- **Frontend:** Next.js and TypeScript show the catalog, optimized for fast first impressions at the live event.
