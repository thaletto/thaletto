## Overview

**Ascendant** is a developer ecosystem for sidereal astrology. Every calculation runs locally, with no hosted API and no external calls.

- **TypeScript library**: an Effect-first library that computes charts, dashas, Ashtakavarga scores, Jaimini results, and transits
- **Python library**: a Python library for charts, dashas, yogas, Ashtakavarga, and Jaimini
- **Agent skill**: turns a saved birth record into a source of truth and pairs it with a deterministic KP algorithm, so the AI works from computed positions instead of guessing them
- **Birth Chart Calculator**: a browser-based tool on the docs site covering Navamsha, Dasha, Jaimini, KP, and Sarvashtakavarga

## Problem

AI agents hallucinate astrology values when they reason from memory, and interpretations buried in model prompts can’t be audited. Meanwhile, the underlying calculations are precise and demanding:

- **Vimshottari Dasha** requires arithmetic anchored to the Moon’s natal nakshatra.
- **Divisional charts** (sixteen in all) transform planetary longitudes by specific ratios.
- **Yogas** number in the hundreds across canonical texts.
- **Ashtakavarga** adds a scoring matrix of 360 cells.

Existing software rarely exposes any of this as programmatic, agent-ready tooling.

## Approach

Ascendant is an end-to-end workflow across four surfaces:

- The **TypeScript library** does the math with Effect services.
- The **Python package** mirrors it for Python runtimes.
- The **agent skill** saves birth records and answers readings with cited evidence.
- The **calculator** demonstrates the whole pipeline interactively.

### TypeScript library

The `astro-ascendant` package computes everything through composable Effect services. Provide a UTC moment, latitude, longitude, and optional birth sex. `Chart.generate` calculates shared placements once and returns cusp-aware charts: D1 first, with divisions like D9 on request. The Dasha, Ashtakavarga, Jaimini, and transit modules reuse those placements.

It covers Vimshottari, Chara, and Sthira dashas, Ashtakavarga, Jaimini results, and transit searches for ingresses, longitude hits, cusp crossings, and retrograde stations. Ayanamsa and house system are typed parameters with immutable defaults. The package offers 47 ayanamsas and 13 house systems, and the default layer uses Krishnamurti and Placidus.

A long-lived `ManagedRuntime` shares one position cache across calls, so repeated charts and transit scans skip the native ephemeris.

```sh
bun add astro-ascendant effect
```

### Python library

The `astro-ascendant` package on PyPI computes the main domains locally with Swiss Ephemeris through `pyswisseph`. It needs Python 3.11 or later. It covers divisional charts, Vimshottari Dasha timelines, current Dasha lookups, yoga results, Ashtakavarga, and a seven-karaka Jaimini core. Results are plain dictionaries and lists. Charts use the sidereal zodiac, with Lahiri ayanamsa and Whole Sign houses as defaults.

Override the ayanamsa and house system per instance, or pass a typed, immutable `AscendantConfig`. Explicit arguments win over `config`, and `config` wins over the defaults.

```sh
pip install astro-ascendant
```

### Agent skill

The skill lives in `astro-ascendant/skills` and works in OpenCode, Claude Code, Codex, Cursor, Gemini CLI, Copilot, and more. One command detects the agents you have, asks for project or global scope, and installs the plugin where a tool has one and the skill everywhere else:

```sh
npx ascendant-skills install
```

It takes three arguments:

- `add` creates or refreshes a reusable `persons/<name>/` record from exact birth data.
- `setup` installs calculation dependencies once per working directory.
- `analysis` answers a reading or timing question from the saved record, grounding claims in stored charts and method references. KP handles timing and yes/no questions; Parashari handles promise, quality, and synthesis.

Person memory accumulates only confirmed events, so readings stay consistent across sessions.

### Birth Chart Calculator

The docs site runs the TypeScript library end to end: Navamsha, Dasha, Jaimini, KP, and Sarvashtakavarga from a birth moment and location.

## How It Works

```typescript
import { Chart, Runtime } from 'astro-ascendant'
import { DateTime, ManagedRuntime } from 'effect'

const input = Chart.ChartParams.make({
  moment: Chart.Moment.make({
    date: DateTime.makeUnsafe('2000-01-01T12:00:00.000Z'),
  }),
  latitude: 12.9716,
  longitude: 77.5946,
  sex: 'Male',
})

const runtime = ManagedRuntime.make(Runtime.MainLayer)
const calculation = await runtime.runPromise(Chart.generate(input, [9]))

console.log(calculation.charts[0]) // D1
console.log(calculation.charts[1]) // D9

await runtime.dispose()
```

The result holds shared placements plus the D1 and D9 charts.

For agent-driven readings, install the skill:

```sh
npx ascendant-skills install
```

On OpenCode, install the plugin as well:

```sh
opencode plugin add opencode-ascendant
```

Then save a record and ask a question:

```sh
/ascendant add
/ascendant analysis
```
